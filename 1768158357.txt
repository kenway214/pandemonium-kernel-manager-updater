Pandemonium Kernel Manager 3.2


## Core Features

- Root-aware kernel management with live monitoring and safe apply controls.
- Per-app thermal profiles with universal and per-app control.
- New Live Monitoring section
- Kernel flasher with partition detection, image flashing, and backup/restore flows.
- Game Control Centre with overlay tools and per-app behavior. (wip)

## Performance & Tuning

- CPU control: governors, cluster tuning, core controls, CPU sets.
- GPU control: frequency limits, governors, enforce mode, advanced tuning.
- Scheduler tuning with enforce mode.
- I/O manager controls.
- Memory and zRAM tuning (swappiness, dirty ratios, compression options).

## Display & Visual
- LumaTune: saturation and high-brightness controls.
- KCAL configuration for display calibration.

## Thermal Management
- Thermal Profiles (Xiaomi): universal and per-app modes.
- Profile detection with clear support messaging.

## K-profile Management

- Dedicated section to manager kprofiles if supported by kernel
